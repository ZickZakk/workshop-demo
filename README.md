# Match API (demo project)

A small demo project for the AI workshop. The API is **specified in Markdown**: one file per endpoint in `endpoints/`.

| Endpoint     | File                         |
| ------------ | ---------------------------- |
| CreateTeam   | `endpoints/create-team.md`   |
| CreateMatch  | `endpoints/create-match.md`  |
| GetMatch     | `endpoints/get-match.md`     |

## Check

