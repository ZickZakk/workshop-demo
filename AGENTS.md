# AGENTS.md

## Project
Beginner's guide to soccer. One Markdown chapter per file.

## Style
- Audience: complete beginners; explain every term the first time it appears
- Each section: one `##` heading, then 3–5 sentences or at most five bullets
- British English ("pitch", "match"), metric units
- Bold key terms; follow the style of the section "Fouls and cards"

## Boundaries
- Only edit the section you were asked about
- Check your changes with `git diff` before finishing
